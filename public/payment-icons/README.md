# أيقونات طرق الدفع — `public/payment-icons/`

هذه أيقونات SVG تُعرض في شاشات البيع والتحصيل والمصروفات، بجانب كل طريقة دفع.
المصدر الوحيد للحقيقة هو جدول `public.payment_methods`، وعمود `icon_key` يربط كل
طريقة بأيقونتها هنا.

---

## كيف يُعرض الرمز؟ — سلسلة واحدة بلا تكرار

```
public.payment_methods.icon_key   (القاعدة: مفتاح نصي مثل 'kuraimi')
        │
        ▼
public/payment-icons/manifest.json   (المفتاح → اسم الملف)
        │
        ▼
/supabase    ──►  src/lib/payments/payment-icons.ts   (الدالة paymentIconUrl)
        │
        ▼
<img src="/payment-icons/kuraimi.svg">   (الواجهة)
```

- **القاعدة لا تعرف الملفات:** `icon_key` مفتاح نصي فقط، فلا يتسرّب رابط أو مسار
  إلى قاعدة البيانات.
- **الواجهة لا تعرف الملفات المسمّاة يدويًا:** تقرأ من الـmanifest، فتغيير اسم ملف
  لا يمسّ السطور التي تستعملها.
- **مفتاح مجهول لا يكسر الشاشة:** يعود إلى `generic.svg`.

## الملفات

| الملف               | المفتاح (`icon_key`) | يُستخدم لـ                   |
| ------------------- | -------------------- | ---------------------------- |
| `cash.svg`          | `cash`               | نقداً                        |
| `credit.svg`        | `credit`             | آجل                          |
| `bank-transfer.svg` | `bank-transfer`      | تحويل بنكي عام، شيك          |
| `kuraimi.svg`       | `kuraimi`            | بنك الكريمي                  |
| `bank.svg`          | `bank`               | بنك اليمن الدولي وأي بنك عام |
| `mobile-money.svg`  | `mobile-money`       | جوالي والمحفظة العامة        |
| `wallet.svg`        | `wallet`             | جيب، فلوسك، ون كاش           |
| `card.svg`          | `card`               | بطاقة / شبكة                 |
| `split.svg`         | `split`              | دفع بأكثر من طريقة           |
| `generic.svg`       | `generic`            | الاحتياط لأي مفتاح غير معروف |

`manifest.json` هو السجل الذي يقرأه الكود. عند إضافة مفتاح جديد في القاعدة، أضفه
هنا واذكر ملفه.

## ⚠️ ملاحظة قانونية مهمة — اقرأها قبل النشر لعميل

هذه الأيقونات **رسوم رمزية عامة أنشأناها** (درع، محفظة، بطاقة…) بألوان متناسقة مع
النظام. **ليست الشعارات الرسمية** لبنك الكريمي أو جوالي أو جيب أو فلوسك أو ون كاش
أو بنك اليمن الدولي.

**لماذا؟** الشعار الرسمي علامة تجارية مملوكة لصاحبها. وضع نسخة غير مرخّصة منه في
منتج يُشغّل لعميل قد يُعرّضه لمخالفة قانونية. ولم نجد نسخًا رسمية بصيغة SVG
متاحة للاستخدام من مصادر موثوقة.

**ماذا تفعل لتحصل على الشعارات الرسمية؟**

1. اطلبها من العميل — البنك أو المحفظة التي يتعامل معها يزوّد عملاءه بملف الشعار
   (عادةً PNG بخلفية شفافة أو SVG).
2. أو حمّلها من موقع المؤسسة الرسمي (قسم «العلامة التجارية» أو «الصحافة») إن
   سمح بالاستخدام.
3. ضع الملف هنا باسم المفتاح نفسه (`kuraimi.svg` …)، فيُعرض تلقائيًا — **بلا
   تعديل أي كود ولا قاعدة بيانات**.

البنية **جاهزة للاستبدال**: بمجرد أن تضع الملف الرسمي بنفس الاسم، يظهر في كل
الشاشات. لا تشعر بأنك مضطر لتعديل شيء.

## كيف تضيف أيقونة لطريقة دفع جديدة؟

1. أضف الصف في `supabase/payment_methods` (البذرة `08_payment_methods.sql`) مع
   `icon_key = 'my-method'`.
2. أنشئ `public/payment-icons/my-method.svg`.
3. أضف `"my-method": "my-method.svg"` في `manifest.json`.

انتهى — الشاشات تعرضها بلا أي تعديل في الواجهة.

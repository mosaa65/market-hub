# أرشيف السكربتات القديمة (Scripts Archive)

هذا المجلد يحتوي على السكربتات المؤقتة، اختبارات القبول القديمة، وفحوصات التشخيص التي تم تنفيذها أثناء مراحل التطوير السابقة. تم نقلها إلى هنا للحفاظ عليها كمرجع تاريخي وتصفية المجلد الرئيسي `scripts/`.

## هيكل الأرشيف:

1. `acceptance-tests/`: اختبارات القبول للمحركات (دفتر الأستاذ، المحاسبة، المخزون، تقارير المبيعات).
2. `milling-diagnostics/`: فحوصات سياسات الأمان (RLS) وحسابات المطاحن القديمة.
3. `qa-tests/`: سكربتات فحص تسجيل الدخول والتصفح الآلي لجلسات QA.
4. `legacy-fixes/`: سكربتات الإصلاحات السريعة لبيانات سابقة.
5. `diagnostics/`: سكربتات فحص الكتالوج، المخططات، والسمات.
6. `temporary/`: سكربتات تجارب فردية وبذور مؤقتة.

> **ملاحظة:** لا تعتمد على هذه السكربتات في عمليات التشغيل اليومية الحالية، استخدم فقط السكربتات الموجودة في المجلد الأب `scripts/` أو عبر لوحة التحكم `db-control.bat`.

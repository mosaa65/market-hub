# خطة إعادة هيكلة شاشة الإعدادات
## 1. Inventory الإعدادات الحالية
تم حصر الإعدادات من `src/routes/_app.settings.tsx` ومكونات الإعدادات الحالية فقط:

- **معلومات المنشأة:** الاسم التجاري، الاسم القانوني، الرقم الضريبي، الهاتف، البريد الإلكتروني، العنوان.
- **الفواتير وPOS:** العملة، رمز العملة، نسبة الضريبة، بادئة الفاتورة، خدمة/أجرة التركيب، وضع الباركود، رابط الشعار المطبوع.
- **الطباعة والقوالب:** قوالب فواتير العملاء والمخزون، أحجام الورق، الطباعة التلقائية، وحقول ظهور المستندات، مع المعاينة.
- **تخصيص النشاط والفهرس:** ملف النشاط و{الموديولات الحالية عبر `CatalogModulesDialog`.
- **الباقة والاشتراك:** الباقة الحالية، الاستهلاك، حدود الموارد والموديولات الموجودة عبر `SubscriptionSettingsCard`.
- **النسخ الاحتياطي:** إعدادات النسخ الاحتياطي، السجل، الإنشاء والاستعادة الموجودة عبر `BackupSettingsCard`.
- **نظام الأرقام:** تفضيل الأرقام اللاتينية/العربية الموجود عبر `getDigitPreference` و`setDigitPreference`.
- **المظهر واللغة:** العربية/الإنجليزية الموجود عبر `useI18n`.

لا تضيف الخطة أي إعداد أو حقل أو Toggle أو Feature جديد؛ هي تعيد ترتيب العناصر أعلاه فقط.

## 2. إعادة التصنيف
سيتم عرض كل مجموعة موجودة كقسم مستقل في سجل الإعدادات: المنشأة، الفواتير وPOS، الطباعة والقوالب، تخصيص النشاط، الباقة والاشتراك، النسخ الاحتياطي، نظام الأرقام، والمظهر واللغة.

## 3. شكل Settings Hub
عنوان واضح ووصف مختصر، ثم بحث موحد بصرياً مع `VortexSearchInput`، وبطاقات أقسام بسيطة تستخدم الأيقونات والعناوين والأوصاف الحالية. نتائج البحث تقتصر على بيانات الإعدادات الحالية وتوجه المستخدم إلى القسم المعني.

## 4. Desktop / Laptop
نمط Master-Detail: شريط تنقل خاص بالإعدادات في العمود الأيسر ومنطقة تفاصيل مستقلة في العمود الآخر، دون خلطه مع شريط التطبيق الرئيسي. البحث أعلى المحتوى.

## 5. Mobile
عند فتح Settings تظهر قائمة الأقسام فقط. اختيار قسم يفتح تفاصيله داخل الصفحة مع زر رجوع. لا يستخدم شريط Desktop الجانبي على الهاتف.

## 6. البحث
يعاد استخدام `VortexSearchInput` الموجود في البحث الرئيسي (نفس الأيقونة، الحواف، الاختصار `/`، المسح، وحالة التركيز). على Desktop يظهر أعلى Hub، وعلى Mobile يكون ثابتاً أسفل الشاشة (`position: fixed`) أثناء Hub فقط.

## 7. سلوك البحث
يبحث في أسماء الأقسام وأوصافها وأسماء الحقول الموجودة فعلياً. اختيار النتيجة يفتح القسم المرتبط بها مباشرة، من دون إنشاء إعدادات أو نتائج وهمية.

## 8. Mobile fixed search
يبقى البحث مثبتاً أسفل viewport مع مساحة safe-area، ويختفي بالكامل عند دخول Detail Page. يعود عند الضغط على رجوع إلى Hub دون تغيير منطق البيانات أو الحفظ.

## 9. Detail Page
تعرض صفحة التفاصيل القسم الحالي ومكونه الموجود كما هو، مع الحفاظ على كل الحقول، الحفظ، الصلاحيات، API، Supabase، LocalStorage، والتحقق الحالي. يبقى زر الحفظ العام واضحاً في أعلى الصفحة.

## 10. المكونات المعاد استخدامها
`SettingsSidebar`, `settings-registry`, أقسام `src/components/settings/sections/`, `VortexSearchInput`, مكونات UI الحالية، `PrintSettingsCard`, `BackupSettingsCard`, و`SubscriptionSettingsCard`.

## 11. الملفات المستهدفة
- `src/routes/_app.settings.tsx`
- `src/components/settings-layout.tsx`
- `src/components/settings-sidebar.tsx`
- `src/components/settings-registry.ts`
- مكونات أقسام صغيرة لعرض إعدادات الأرقام والنسخ الاحتياطي عند الحاجة.

**تأكيد النطاق:** لا تتم إضافة أي Setting جديد مقارنة بما كان موجوداً قبل التنفيذ، ولا يتم تغيير مخطط قاعدة البيانات أو عقود API أو business logic.

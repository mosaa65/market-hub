# معايير وقواعد مسارات النظام والتوجيه (Routing Conventions)

> **إطار العمل:** TanStack Start & TanStack Router  
> **الدليل الإرشادي:** مجلد `src/routes/`

---

## 1. فلسفة التوجيه القائم على الملفات (File-based Routing)

يعتمد إطار العمل TanStack Start على التوجيه التلقائي عبر أسماء الملفات. كل ملف بصيغة `.tsx` داخل المجلد `src/routes/` يمثل مساراً تشغيلياً مستقلاً.

> [!WARNING]
> يمنع منعاً باتاً إنشاء مجلدات مثل `src/pages/` أو `src/routes/_app/index.tsx` أو `app/layout.tsx`، حيث أن هذه المعايير خاصة بـ Next.js و Remix ولا تتوافق مع معمارية هذا المشروع. المخطط الجذري الوحيد المعتمد هو `src/routes/__root.tsx`.

---

## 2. جدول تسميات الملفات والروابط المقابلة

| اسم الملف في الكود       | رابط الـ URL الناتج  | نوع المسار ووظيفته                                             |
| :----------------------- | :------------------- | :------------------------------------------------------------- |
| `index.tsx`              | `/`                  | الصفحة الرئيسية / الترحيبية                                    |
| `about.tsx`              | `/about`             | صفحة تعريفية ثابتة                                             |
| `users/index.tsx`        | `/users`             | صفحة قائمة المستخدمين                                          |
| `users/$id.tsx`          | `/users/:id`         | مسار ديناميكي (رمز `$` مجرد دون أقواس معقوفة)                  |
| `posts/{-$category}.tsx` | `/posts/:category?`  | مسار بمعامل اختياري (Optional Segment)                         |
| `files/$.tsx`            | `/files/*`           | مسار شامل (Splat - يُقرأ عبر المعامل `_splat`)                 |
| `_layout.tsx`            | مسار تخطيط داخلي     | يعرض المكونات التابعة عبر `<Outlet />` دون التأثير على الـ URL |
| `__root.tsx`             | المخطط الجذري للنظام | يغلف كامل التطبيق ويدير السياقات العامة وشريط التنبيهات        |

---

## 3. مسار التطبيق المحمي (`_app.*.tsx`)

جميع الصفحات التشغيلية للنظام (POS، المخزون، المشتريات، المبيعات، الحسابات، الإعدادات) تبدأ بالبادئة `_app.`، مثل:

- `_app.pos.tsx` → نقطة البيع السريعة.
- `_app.products.tsx` → إدارة الأصناف ودليل المنتجات.
- `_app.inventory.tsx` → إدارة المخزون والجرد.
- `_app.account-statement.tsx` → مركز الكشوفات الموحد.
- `_app.settings.tsx` → إعدادات النظام والشركة.

### شجرة المسارات الآلية (`routeTree.gen.ts`)

ملف `src/routeTree.gen.ts` يتم توليده تلقائياً بواسطة حزمة Vite الخاصة بـ TanStack Router. **لا تقم بتعديله يدوياً**؛ حيث يتحدث تلقائياً بمجرد إنشاء أو حذف أي ملف مسار جديد في `src/routes/`.

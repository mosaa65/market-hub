# دليل تشغيل وتجربة نظام Market-Hub ERP بدون إنترنت وتجميع حزمة سطح المكتب (Tauri Windows Desktop App)

> **تاريخ الدليل:** 2026-09-30  
> **الفرع الحالي:** `yunis-offline-architecture`

---

## 🎯 الجزء الأول: التجربة السريعة للعمل بدون إنترنت (Offline Mode) داخل المتصفح

يمكنك تجربة المعمارية المنجزة فوراً واختبار تنفيذ الفواتير والتحويلات والعمليات المالية عند انقطاع الإنترنت داخل المتصفح:

### 1. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على العنوان [http://localhost:8080](http://localhost:8080).

### 2. محاكاة انقطاع الإنترنت (DevTools Offline Simulation):
1. اضغط `F12` لفتح أدوات المطورين (DevTools).
2. انتقل إلى تبويب **الشبكة (Network)**.
3. قم بتغيير حالة الشبكة من **No throttling** إلى **Offline**.

### 3. ماذا ستلاحظ عند انقطاع الإنترنت؟
- تتغير شارة النظام أعلى الشاشة فوراً إلى: `غير متصل (Offline)`.
- يمكنك إجراء عمليات البيع في الـ POS، وتحصيل دفعات العملاء، وتحويل المخزون بين المستودعات.
- يتم حفظ كافة العمليات فوراً في قاعدة البيانات المحلية (IndexedDB/LocalStorage) وتوليد أرقام مراجع محلية قابلة للطباعة مثل: `POS-DEV01-20260930-0001`.
- تتم إضافة المظاريف المالية والمخزنية تلقائياً إلى طابور المزامنة `Outbox`.

### 4. محاكاة عودة الإنترنت (Auto-Sync):
1. أعد خيار الشبكة في DevTools إلى **No throttling**.
2. يتعرف محرك `SyncEngine` فوراً على عودة الشبكة ويقوم بإرسال العمليات المعلقة في طابور `Outbox` إلى Supabase وتحديث أرقام الفواتير الرسمية صامتة دون تعطيل المستخدم!

## 📦 الجزء الثاني: تثبيت وتجميع تطبيق سطح المكتب (Tauri Windows Installer)

لتثبيت برنامج Market-Hub كتطبيق سطح مكتب حقيقي يعمل بنظام Windows مع قاعدة بيانات محليّة SQLite دون الحاجة لمتصفح:

### المتطلبات السابقة (تثبيت على جهاز المطور):
1. **تثبيت لغة Rust:** تحميل وتشغيل [rustup-init.exe](https://rustup.rs/) (اختر الإعداد الافتراضي 1).
2. **C++ Build Tools:** تتوفر تلقائياً مع Visual Studio (مع تحديد خيار *Desktop development with C++*).

---

### خطوات إعداد حزمة Tauri لسطح المكتب:

#### الخطوة 1: تثبيت مكتبة Tauri CLI في المشروع
```bash
npm install --save-dev @tauri-apps/cli
```

#### الخطوة 2: تهيئة ملفات Tauri للمشروع
```bash
npx tauri init
```
سيطلب منك المدخلات التالية (يمكنك استخدام القيم الافتراضية):
- **App Name:** `MarketHubERP`
- **Window Title:** `Market-Hub ERP`
- **Web assets path:** `../dist`
- **Dev server URL:** `http://localhost:8080`
- **Build command:** `npm run build`

#### الخطوة 3: تشغيل التطبيق كتطبيق سطح مكتب في بيئة التطوير
```bash
npx tauri dev
```
سيفتح التطبيق في نافذة برنامج مستقلة على Windows مع تفعيل دعم قواعد البيانات المحلية SQLite.

---

### 🚀 الخطوة 4: تجميع حزمة التثبيت النهائية Windows (.exe / .msi)

لتوليد ملف تثبيت ينقله العميل ويقوم بتثبيته مثل أي برنامج عادي:

```bash
npx tauri build
```

بعد انتهاء عملية التجميع، ستجد ملف التثبيت المكتبي التلقائي داخل المجلد:
`src-tauri/target/release/bundle/msi/MarketHubERP_1.0.0_x64_en-US.msi`  
أو  
`src-tauri/target/release/bundle/nsis/MarketHubERP_1.0.0_x64-setup.exe`

---

## 🛠️ كيف يستعمله العميل في المتجر عند انقطاع الإنترنت لمدة طويلة؟

1. يقوم العميل بتثبيت ملف `MarketHubERP-setup.exe` على جهاز الكمبيوتر في المتجر.
2. يدخل حسابه أول مرة وهو متصل بالإنترنت ليقوم النظام بحفظ كاش المصادقة والبيانات المرجعية للأصناف والمستودعات.
3. عند انقطاع الإنترنت، يواصل البرنامج العمل يومياً (مبيعات، مخزون، مدفوعات، طباعة فواتير مراجع محلية).
4. عند عودة الإنترنت بعد أيام، يستشعر محرك `SyncEngine` الشبكة ويقوم بمزامنة طابور Outbox كاملاً مع سيرفر Supabase بطريقة أوتوماتيكية آمنة ومحمية ضد تكرار الفواتير.

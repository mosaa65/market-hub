# خطة: حقل الأرقام الموحد — `AmountInput` (المبالغ) + `QuantityInput` (الكميات)

> **الحالة العامة:** ✅ مكتملة — المكوّنان مبنيان ومستخدمان في كل شاشات النظام، **ولا يوجد أي `type="number"` في `src/`**، وقاعدة eslint تمنعه مستقبلًا.
> **الوثيقة التفصيلية:** [`docs/plans/amount-and-quantity-input-unified-plan.md`](./plans/amount-and-quantity-input-unified-plan.md)
> **آخر تحديث:** 2026-10-18
>
> **الهدف:** مكوّنان فقط لكل حقول الأرقام في النظام، كلاهما `type="text"` + `inputMode="decimal"` فلا يتغيّر الرقم بعجلة الماوس إطلاقًا، مع فاصلة آلاف وتفقيط للمال، وحدود وكسر عشري للكميات. **أزرار الزيادة/النقصان تبقى كما هي** في شاشاتها.

---

## التحليل (ما وجدته في المشروع)

### المشكلة

- أكثر من **62 موضعًا** يستخدم `<input type="number">` خام للمال والكميات (POS، الفواتير، المشتريات، الدفعات، الأرصدة الافتتاحية، الأصول الثابتة، الطحن، التسويات...).
- مشكلة مؤكدة: عند التمرير بالماوس فوق حقل `type="number"` مركّز، المتصفح يغيّر الرقم تلقائيًا.

### الأصول الجاهزة (لا حاجة لبناء من الصفر)

| الأصل                          | المسار                                                                                         | الاستفادة                                                                                    |
| ------------------------------ | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| التفقيط                        | `src/lib/templates/tafqeet.ts` → `numberToArabicWords()`                                       | جاهزة تمامًا: 100 → "مائة ريال"، 1000 → "ألف ريال"، مع دعم الكسور والعملات (YER/SAR/USD/EUR) |
| التنقية والفاصلة أثناء الكتابة | `src/design/number.ts` → `groupWhileTyping()`, `sanitizeNumericString()`, `toAsciiDigits()`    | فاصلة كل 3 أرقام دون قفزة المؤشر + تطبيع الأرقام العربية                                     |
| رمز/اسم العملة من الإعدادات    | `src/lib/format.ts` → `getCompanyCurrencySymbol()` (كاش `CompanyProfile` ← `company_settings`) | الربط بنظام الإعدادات الموحد — تغيير العملة في الإعدادات ينعكس تلقائيًا                      |
| مكون جزئي موجود                | `src/components/vortex-ui/inputs/vortex-number-input.tsx`                                      | يستخدم للكميات فقط؛ سيبقى للكميات و`AmountInput` للمال                                       |

## المرحلة 1 — بناء المكون الموحد `AmountInput` ✅

**الملف:** `src/components/ui/amount-input.tsx`

**المهام:**

- [ ] إدخال بصري `type="text"` مع `inputMode="decimal"` (وليس `type="number"`) — هذا يحل مشكلة عجلة الماوس نهائيًا لأن المتصفح لا يطبق سلوك spinner/wheel أصلاً.
- [ ] فاصلة آلاف أثناء الكتابة عبر `groupWhileTyping()` من `src/design/number.ts` مع حفظ موضع المؤشر.
- [ ] تطبيع الأرقام العربية `٠١٢٣` → ASCII تلقائيًا عبر `toAsciiDigits()`.
- [ ] API بسيط:
  ```tsx
  <AmountInput
    value={amount} // number | null
    onValueChange={setAmount}
    decimals={2}
    min={0}
    currency="YER" // اختياري — الافتراضي من الإعدادات
    showInWords // افتراضي true
  />
  ```
- [ ] لعرض رمز العملة: قراءة من `getCompanyCurrencySymbol()` (الربط بنظام الإعدادات الموحد).

**التحقق:**

- [ ] `npm run lint` نظيف.
- [ ] كتابة 1,234.5 تظهر بفاصلة، ولصق رقم عربي ٠٥٠ يتحول لـ 50.

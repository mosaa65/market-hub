# مركز التوثيق والخطط الهندسية الشامل (Documentation Center) — Vortex ERP

مرحباً بك في مركز التوثيق الموحد لنظام **Vortex ERP (Market Hub)**.  
تم تنظيم وهيكلة كافة وثائق المشروع، والخطط الاستراتيجية والتشغيلية، وتقارير التدقيق الفني، ومعمارية النظام، ودليل قاعدة البيانات في مجلدات متخصصة ومصنفة بعناية مع ترجمة عربية تقنية واحترافية تحافظ على المصطلحات البرمجية الدقيقة.

---

## فهرس التوثيق السريع (Quick Navigation)

```text
docs/
├── agent_instructions/  # تعليمات وقواعد الـ Agent (AGENTS.md، VORTEX AI Rules)
├── agents/              # توثيقات خاصة بالوكلاء
├── plans/            # خطط التطوير والترقية وتجزئة الباقات ومحركات النظام
├── reports/          # تقارير التدقيق الفني، جرد المكونات، ووثائق التسليم
├── architecture/     # المعمارية الشاملة، معايير التوجيه، وإرشادات المطورين
├── accounting/       # تقارير وأدلة نظام المحاسبة
├── milling/          # كل ما يتعلق بالمطحنة: خطط، تحليلات، مقارنات سير العمل
├── product/          # تصميم وخدمة المنتجات والمخزون
├── configuration/    # توثيق متغيرات البيئة (env cloud/local)
├── database/         # المعجم الكامل لقاعدة البيانات وملاحظات أمان الترحيلات
└── seed/             # ملفات بيانات SQL التجريبية (غير مُشغَّلة على قاعدة الإنتاج)
```

> مجلدات مرجعية خارج `docs/`:
>
> - `logs/` — سجلات التشغيل والبناء (غير متتبعة في git)
> - `scripts/qa/` — سكربتات اختبار الجودة، `scripts/fixes/` — سكربتات إصلاح
> - `supabase/docs/` — خطط وتقارير وأدلة قاعدة البيانات (Schema, Migrations, RLS)

### قاعدة التسمية والتاريخ

لأي ملف توثيق جديد، اتبع هذا النمط حتى تعرف فورًا حالته وتاريخه:

```
YYYY-MM-DD_<الحالة>_<الموضوع>.md
```

- `<الحالة>`: `plan` (خطة قيد التنفيذ/مقترحة) أو `report` (تقرير مكتمل) أو `guide` (توثيق دائم) أو `audit` (تدقيق).
- مثال: `2026-10-18_plan_milling-v2.md`
- عند اكتمال خطة: انقل النتيجة كتقرير إلى `reports/` وعلّم الخطة `COMPLETED`.
